# PaintScript 0.1 definition

This file only contains the direct definition of
"PaintScript 0.1". If you want to learn PaintScript, read "0.1 def.md" instead.

## About

PaintScript is a simple dynamic programming language used
for controlling sprites and other display items in an application called "xPaint".

It has syntax similar to JavaScript and might remind you of ActionScript a bit.
The language was made as a "Scratch" like language, but with text instead of blocks.

## Events

In PaintScript, a program is controlled completely by events.
In order to handle an event, prepend the event name with the '@' symbol.

Here is an example:

```text
@Start {}
```

In this example, we create a handler for an event called "Start".
The Start event get's activated when the play button is clicked in the GUI editor (xPaint).
This is similar to Scratch's "When Green Flag Clicked" block.

Just like Adobe Flash ActionScript, the language is tied to the ide, in this case, xPaint.

In PaintScript 0.1 there are many events, here is a list of them all:

Events can have multiple handlers, so it's not just one.

```text

// Similar to Scratch's "When Green Flag Clicked" block.
@Start {}

// When any message is broadcast.
@receive {}

// When a specific message is broadcast
@receive Message1 {}

// Multi message handler
@receive Message1, Message2 {}

// This Sprite or object was clicked.
@OnClick {}

// Any key pressed?
@Keypress {}

// When a specific key is pressed. (Example: Space key.)
@Keypress SpaceKey {}

// Multi key check. (Any of these keys pressed?)
@Keypress WKey, UpArrowKey, SpaceKey {}

// Custom key check.
@Keypress(key:KeyboardKey) {
	key == KeyboardKey.SpaceKey;
}

// Is mouse being pressed down?
@MouseDown {}

// Is mouse being let go after being down?
@MouseUp {}

// An event can be forcefully activated with the call keyword:

call @Keypress;
call @Keypress(KeyboardKey.SpaceKey);

/*
	The @Refresh event
	
	Unlike most languages, PaintScript does not update automatically.
	You tell PaintScript to refresh the screen yourself.

	Do this by calling the @Refresh event.
*/

call @Refresh;

// To create a custom event, use messages.
// Messages are not defined, but handlers can be created.
// If a message that does not have any handlers is broadcasted, nothing happens.

// If it has handlers, then those handlers will run.

```

## Control flow

PaintScript has an interesting control flow, here it is.

```text

/* Conditionals */

// Normal if condition
if (condition) {}

// If, else if.
if (condition) {} else if (condition) {}

// If, else.
if (condition) {} else {}

// If, else if, else.
if (condition) else if (condition) {} else {}

You can flip the condition as well:

if not (condition) {}
// if/if not (condition) else if/if not etc...

/* Loops */
// Repeat a fixed number of times.
repeat(3) {}
repeat(list.length) {}

// Repeat forever, code cannot go under. This will be the
// final instruction in it's scope.
forever {}

// Repeat until condition is true.
repeat until (condition) {}

// Repeat while condition is true (repeat until false).
while (condition) {}

// For loops.
for (var i = 0; i < size; i++) {}

/* Waiting */

// Wait
wait(3000); // 3000 milliseconds = 3 seconds.

// Wait until (stops current thread and waits until condition is true)
wait until(condition);
```

## Built in functions

PaintScript has a built in library for most Scratch Blocks:

```text
/* Motion blocks */

// Move * steps towards the direction object is facing.
moveSteps(10);

// Turn object Clockwise * degrees.
turnCW(15);

// Turn Counterclockwise * degrees.
turnCCW(15);

// Go to random position within the stage size.
gotoRandom();

// Go to the mouse pointer.
gotoMouse();

// Go to specified position, x, y.
goto(0, 0);

// Glide to Seconds, x, y.
glideTo(1, 0, 0);

// Point in direction
setDirection(90); // 90 = right;

// Point towards mouse pointer.
pointTowardsMouse();

// Point towards object or sprite.
pointTowards(Stage.getSpriteByName("Sprite_2"));
```
